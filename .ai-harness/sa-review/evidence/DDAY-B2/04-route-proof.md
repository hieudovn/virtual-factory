# DDAY-B2 — 04. Actual route proof

**Claim:** the Bottled Water target line runs as **exactly 8 logical stations in
the frozen order**, driven by configuration, with no legacy station behaviour
retained under a renamed label.

**Machine evidence:** [`machine-evidence.json`](./machine-evidence.json) → `route`

## Configured route (from the runtime, not from documentation)

```json
["BW-FP-BLW01", "BW-FP-RIN01", "BW-FP-FIL01", "BW-FP-CAP01",
 "BW-FP-INS01", "BW-FP-LAB01", "BW-FP-CPK01", "BW-FP-PAL01"]
```

| Check | Result |
|---|---|
| Configured route equals the frozen B1 order | **PASS** (`route_matches: true`) |
| Station count | **8** |
| One station contract per configured position | **PASS** — `["BW-FP-BLW01","BW-FP-CAP01","BW-FP-CPK01","BW-FP-FIL01","BW-FP-INS01","BW-FP-LAB01","BW-FP-PAL01","BW-FP-RIN01"]` |
| Quality-capable stations | **exactly** `["BW-FP-INS01"]` — one consolidated inspection checkpoint |
| Configured cycle durations | `BLW01 12.0, RIN01 10.0, FIL01 18.0, CAP01 14.0, INS01 8.0, LAB01 10.0, CPK01 16.0, PAL01 18.0` s |

## A real unit actually traverses the whole route in order

Unit `BTL-000001` was released automatically and its movement facts
(`UNIT_ENTERED` + `WIP_MOVED` events) record:

```
BW-FP-BLW01 -> BW-FP-RIN01 -> BW-FP-FIL01 -> BW-FP-CAP01
-> BW-FP-INS01 -> BW-FP-LAB01 -> BW-FP-CPK01 -> BW-FP-PAL01
```

`unit_traversal_matches_route: true`, 8 hops. This is the strongest available
proof that the route is real and ordered: it is the unit's observed path through
the engine, not the configuration echoed back.

## No legacy station behaviour is retained

- The eight positions are configured, not adapted from a legacy station list.
- Every contract is generated by `build_line_station_contracts()`, which
  special-cases **no** station id.
- Only the Inspection checkpoint carries `quality_decision`; every other station
  is a pure configured operation with a configured duration.
- No checklist gate, no identity transformation (join), no final disposition and
  no exception routing is configured for any Bottled Water station.
- Domain-token scan over the configuration file and all runtime surfaces is
  **clean** (evidence 10).

Asserted by `test_t01_exact_eight_station_route_and_order` and
`test_t02_automatic_unit_progression_without_manual_actions`.
